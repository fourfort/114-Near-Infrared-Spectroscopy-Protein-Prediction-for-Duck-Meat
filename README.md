# 🦆 Near-Infrared Spectroscopy Protein Prediction for Indigenous Duck Meat

This repository contains the project files, datasets, and materials developed during the **114 academic year** as part of a research project funded by the Ministry of Agriculture.  
The study focuses on building a **machine learning-based protein content prediction model** for indigenous duck meat using near-infrared (NIR) spectroscopy.  

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## 📝 Project Overview

🌟 **Objective**:  
Develop a reliable and accurate model to predict protein content in indigenous duck meat using NIR spectral data.

📊 **Dataset**:  
- Source: Eastern District Branch, Council of Agriculture, Executive Yuan  
- Samples: 150 indigenous duck meat samples  
- Spectral range: 400–1099.5 nm  

🔬 **Methodology**:  
- Data preprocessing and feature extraction are key steps for stable and accurate predictions.  
- Baseline model: Partial Least Squares (PLS) regression  
- Preprocessing & feature selection: Tested multiple spectral preprocessing methods; **centering** and **Uninformative Variable Elimination (UVE)** performed best.  
- Machine learning models:  
  - PLS (baseline)  
  - Support Vector Machine (SVM)  
  - Decision Tree (DT)  
  - Extreme Gradient Boosting (XGBoost)  

💎 **Contributions**:  
- Main responsibility: programming, model training, and methodology planning  
- Implementation of preprocessing and feature extraction pipelines  
- Model comparison and evaluation
